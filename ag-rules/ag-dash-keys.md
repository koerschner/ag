AG Dash (http://ag:7376) works from the keyboard like Gmail, and its help (?) lists exactly these. Plain keys
work outside text fields and dialogs.

On the board: j/k (or ↓/↑) next/previous card, ←/→ previous/next column, o or Enter open the card, Space
expand/collapse its details, e archive (Undo for a few seconds), ⇧U mark unread, 1–5 the State / Lists /
Workspaces / Routines / ag-rules views.

In an open session: r write a reply (the box starts unfocused), j/k next/previous session, e archive and open
the next, u back to the board.

Anywhere: z undo the last archive (⌘Z too, except in a field with text, where it's the field's own undo), c new
item (or ask where a session is), / search, ? help, ⌘K new item / find a session (even while typing), Esc
closes the image viewer, else leaves the reply box, then closes the panel, ⌥V dictates in the open editor, ⌘↩
sends.
