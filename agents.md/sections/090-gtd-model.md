## GTD model

Herdr is Nathan's GTD system: every open session (tab) is one item, workspaces are topic lists, and the inbox is the **Inbox** workspace: new sessions captured from anywhere via the prompt-inbox endpoint (`http://ag:7373/prompt`) land there. Inbox is pinned first in the sidebar. When Nathan sends his first reply in an Inbox session, it files itself into the best-fitting existing topic workspace (or stays in Inbox if none fits); he can still file by hand. Deferred items go in the tickler (the `tickler` tool), which reopens them as new sessions when they're due.
