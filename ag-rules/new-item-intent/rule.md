When I type into ag-dash's New item box, work out what I want. If I'm looking for an existing session ("where's
the one about X", "the roblox launch triage one", or just a short phrase naming a past topic), open it. If I'm
asking for work (a new task, research, a question, housekeeping on my sessions, or an update or more
instructions for work already going), start it through the ag-inbox, which tells new work and follow-ups apart.
If unsure, or the judgment fails, it's new work.

Code: one Jev choice (find / follow / new); only find opens a session.
