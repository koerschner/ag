## Ag machines (ag-mac, ag-client, ag-engine, ag-phone)

Load the **`ag-machine-ops`** skill for connection details, Keychain items, MCP re-auth recipes, 1Password vault IDs, and computer-use setup. The essentials:

- **Ag** (Always Generating) is Nathan's whole agent system. Its machines: **ag-engine**, rented Linux (Hetzner) and the **session host** since 2026-09-29: every session (tmux via `ag-mux`), every Ag service, and the repos live there (home `/home/nathan`; `/Users/natkoersch` is a symlink to it, so paths from before the move still work); **ag-mac**, the always-on Mac Ag drives for computer use and Mac-only apps and CLIs (the "extremity"; home `/Users/natkoersch`); **ag-client**, the Mac he sits at (home `/Users/nathan`; `ssh ag-client`); and **ag-phone**, his iPhone. Links use the machine-independent address `ag` (a Tailscale Service: `http://ag:7376`, …), never a machine name. Model inference goes through TrueFoundry. `machines/README.md` in the ag repo is the inventory (`ag-host` prints the session host); design in `docs/ag.md` and `docs/tmux-port.md`. Historical conversations call ag-mac `ag` and ag-client `nathan-dev-client`, and ran on ag-mac under Herdr; translate old paths for the current host. Checkout paths containing `seen` are preserved names, not stale ones.
- **From the engine, reach the Mac with `mac`:** `mac run <cmd>` (Mac-only CLIs, Xcode, Keychain), `mac cua "<task>"` (computer use on ag-mac's desktop; the `chatgpt_cua` tool does this for you off the Mac; runs are queued one at a time, so check `mac cua --status` before assuming a slow run failed), `mac push`/`mac pull` (files), `mac show <file|url>`, `mac status`. Call it the moment a task needs macOS; don't move whole sessions to the Mac. The shared MCP gateway runs on the engine (`mcp-gateway.service`), so MCP needs no sign-in per session.
- **Secrets:** `op-ag` reads/writes the canonical arcade.school vault (`jjbrfvemdg4y3prkikxur6thbq`); `op-shared` reads/writes Nathan's everyday personal credentials (vault machine-shared); `op-work` reads/writes non-super-secret work items (vault ag-vault, id `c3qkbcqktsxmi6hnpzpltdbose`, in the Trilogy work account: the Ramp card, infra API tokens such as Hetzner; store new work infra tokens there). Pipe secrets straight into the process that needs them (`op-ag run`/`op-ag read`); never print them into output, logs, arguments, or dotfiles. The engine has `op-ag` and `op-work` but deliberately not `op-shared` (Nathan's personal vault): from the engine use `mac run op-shared …`. Banking, tax, medical, identity, recovery codes, private keys and primary accounts are deliberately out of reach: ask Nathan, never go around it through the 1Password app or browser.
- **Programmatic first; driving the client's desktop is an antipattern.** Use an API, CLI, or MCP tool whenever one exists. Computer use runs on ag-mac (`chatgpt-cua` / the `chatgpt_cua` tool, which hands off to `mac cua` from the engine). Drive the client only when the task truly exists only there (see the skill for the tool and its `--why` rule); a Jev guard blocks unjustified client automation, so don't route around it. When you must use the client, use it to build capacity (mint the missing API key into the vault once), then work programmatically.
- **Permission dialogs:** on ag-mac, agents' macOS permissions all belong to `sshd-keygen-wrapper` (their TCC identity); run `ag-access` to check them and `ag-access allow` to answer a pending prompt (CUA can't click those). Otherwise, when a task stalls on a likely permission prompt or system dialog, grant it yourself with computer use on the machine showing it, then confirm the step proceeds. Ask first only if it grants more than the task needs, authorizes something destructive, or needs a secret the task doesn't already authorize.
- **Tell Nathan what ag needs.** If something on an Ag machine is missing, expired, or under-permissioned, fix it yourself when it's safe, capture the fix in ag (or dotfiles, for personal config), and tell him. If it needs him (a login, a broader grant, a new secret), stop and ask clearly and kindly; don't silently work around it or drop the task.
