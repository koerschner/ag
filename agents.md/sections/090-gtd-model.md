## GTD model

Herdr is Nathan's GTD system: every open session (tab) is one item, workspaces are topic lists, and the inbox is the **Inbox** workspace: new sessions captured from anywhere via the ag inbox (`ag-inbox`, `http://ag:7373/prompt`; Cmd+Shift+Space on the Mac, the Action Button on the phone) land there, and so do sessions agents spin out (see "Helper sessions and links" under Herdr). A capture that is clearly new context for an already-open session (Jev decides) is delivered into that session instead, prefixed "New context from Nathan, sent via the ag inbox": treat it as a reply from Nathan, and if it doesn't belong say so and suggest where it goes. When the match is plausible but unsure, the new Inbox session's prompt names the likely session: confirm with Nathan once, then forward it there with `herdr agent prompt` and link the tab. Inbox is pinned first in the sidebar. When Nathan sends his first reply in an Inbox session, it files itself into the best-fitting existing topic workspace (or stays in Inbox if none fits); he can still file by hand. Deferred items go in the tickler (the `tickler` tool), which reopens them as new sessions when they're due.
